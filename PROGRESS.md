# VersoCon — Progress

VersoCon: convertitore di file con GUI web desktop-stile anime giapponese.
Stack: Python 3.11+ / FastAPI / Pillow + pillow-heif / Frontend HTML+CSS+JS (no build step).
UI servita via pywebview (Edge WebView2) con fallback browser di default.
